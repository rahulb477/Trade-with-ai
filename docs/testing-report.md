Notable behaviours that are explicitly tested rather than assumed:

- Fills occur at the **next bar's open** (no look-ahead).
- When a bar touches both a stop and a target, the **stop wins**.
- A gap through the stop fills **at the open**, producing a loss worse than −1R.
- Position size always **rounds down**, never up.
- `charge`-free break-even at 2:1 is 33.3%; with `cost_R = 0.1` it rises to 36.7%.
- Sharpe returns `None` below 30 observations and refuses a constant series.
- `wilson_interval(5, 10)` = (0.237, 0.763).
- Synthetic data is deterministic under a fixed seed.

## 12. Integrations that require credentials

None are bundled. Each would require credentials **and** a working adapter (see
[`docs/limitations.md`](limitations.md) §5). Listed so the requirement is explicit rather than discovered:

| Integration | What it would add | Credential | Adapter status |
|-------------|-------------------|-----------|----------------|
| Licensed market-data vendor | Computed indicators on live/lagged OHLCV | API key or OAuth | Interface only |
| Broker/exchange data API | Quotes, depth, order flow | Broker credentials | Interface only |
| Options chain provider | OI, IV, Greeks | API key | Interface only |
| News/wire provider | Cited headlines with timestamps | API key | Interface only |
| Economic-calendar provider | Scheduled events for the risk gate | API key or licence | Interface only |
| Exchange filing portal | Primary-source announcements | Usually no key; may need session cookies | Manual/browser |
| Fundamental-data provider | Statements, ratios | API key | Interface only |

**The skill is fully functional without any of them**, in offline knowledge mode. Credentials are read from
environment variables only, are never logged, and are never committed — see
[`docs/security.md`](security.md) §2.
