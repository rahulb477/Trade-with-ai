## Rules common to all workflows

1. **State the mode** (LEARNING / RESEARCH / PAPER-TRADING) in the first line of output.
2. **Never skip the quality gate.** If data is insufficient, say so before doing any analysis.
3. **Never invent a timeframe, indicator value, or news item** you did not see.
4. **Always produce the three scenarios** for research and paper-trading work, including the no-trade case.
5. **End with sources and gaps**, every time.
