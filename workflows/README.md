# Workflows — Index

Repeatable procedures. Each workflow is a checklist, not an essay: follow it in order.

| Workflow | Use when |
|----------|----------|
| [`screenshot-analysis.md`](screenshot-analysis.md) | A chart image is supplied (the main path) |
| [`multi-timeframe-analysis.md`](multi-timeframe-analysis.md) | Two or more timeframes are available |
| [`breakout-analysis.md`](breakout-analysis.md) | Price is at/through a level |
| [`breakdown-analysis.md`](breakdown-analysis.md) | Price is at/through support |
| [`trap-detection.md`](trap-detection.md) | A break may be false |
| [`news-research.md`](news-research.md) | Context is needed (and browsing exists) |
| [`paper-trading.md`](paper-trading.md) | A hypothetical plan with entry/stop/targets is requested |
| [`beginner-explanation.md`](beginner-explanation.md) | The user is new, or asks "explain simply" |
| [`prediction-logging.md`](prediction-logging.md) | A record must be created before the outcome is known |

## Rules common to all workflows

1. **State the mode** (LEARNING / RESEARCH / PAPER-TRADING) in the first line of output.
2. **Never skip the quality gate.** If data is insufficient, say so before doing any analysis.
3. **Never invent a timeframe, indicator value, or news item** you did not see.
4. **Always produce the three scenarios** for research and paper-trading work, including the no-trade case.
5. **End with sources and gaps**, every time.
