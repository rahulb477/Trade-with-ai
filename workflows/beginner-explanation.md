# Workflow — Beginner Explanation

## When to use
- Mode is LEARNING
- The user says "explain simply", "I'm new", "what does this mean"
- Any analysis report (the Hinglish section is mandatory regardless)

## Step 1 — Calibrate
Identify what the user already knows from their message. Do not over-explain a term they used correctly, and do not
assume knowledge of a term they have not used.

## Step 2 — Use the five-part structure

```
1. Definition     — one sentence
2. Simple         — an everyday analogy, no jargon
3. Technical      — the mechanics, thresholds, edge cases
4. Chart example  — what it looks like and what to check
5. Mistakes + practice
```

For an *analysis* (not a concept), use instead:

```
1. What the market is doing (one sentence)
2. Why (three bullets)
3. What would change that view (one bullet)
4. What to do now (wait / condition)
5. In Hinglish
```

## Step 3 — Translate jargon on first use

| Jargon | Plain |
|--------|-------|
| Support | A price where buyers have shown up before |
| Resistance | A price where sellers have shown up before |
| Breakout | Price closed above a level that had been holding it down |
| Retest | Price came back to check the level it just broke |
| Volume | How much was traded — the "effort" behind a move |
| Momentum | How fast / forcefully price is moving |
| Volatility | How big the swings are |
| Stop loss | The price that proves the idea wrong |
| R | One unit of risk = the distance from entry to stop |
| Divergence | Price and an indicator disagreeing about strength |

## Step 4 — Use an analogy, once

| Concept | Analogy |
|---------|---------|
| Support/resistance | A floor and a ceiling that have been tested a few times |
| Breakout vs fakeout | Stepping outside a room and either staying out or stepping back in |
| Volume confirmation | How many people are pushing a door |
| ATR / position sizing | Packing for the weather: bigger swings need a bigger margin for error |
| R:R | Betting ₹1 to win ₹2 |
| Trend vs range | A river flowing vs a pond sloshing |
| Stop not being a floor | A request, not a guarantee — like a taxi booking at a fixed fare in traffic |

Do not chain three analogies; one is enough.

## Step 5 — Keep it short
A beginner cannot absorb 2,000 words. Target:
- Concept answer: 300–600 words
- Analysis Hinglish section: 150–300 words

## Step 6 — Never do this

| Don't | Why |
|-------|-----|
| Use "smart money", "institutional flow", "liquidity engineering" as explanations | Unverifiable and confusing |
| Say "it will go up" | Prediction presented as fact |
| Skip the invalidation | The most important teaching point |
| Use Hinglish as an excuse for vagueness | It is a translation, not a simplification excuse |
| Give a 12-indicator explanation | Overwhelming |
| Assume chart literacy | Define "wick" the first time |

## Step 7 — Check your own output
Read it back and ask: *would a person who has never seen a chart be able to describe what is happening and what
would prove it wrong?* If no, rewrite.
