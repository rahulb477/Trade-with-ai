## The honest division of labour

| Question | Tool |
|----------|------|
| Where might price react? | Technical analysis |
| What is the company worth? | Fundamental analysis |
| Why did it move today? | News + context |
| Will it keep moving? | Neither, reliably |

This repository is chart-first. Fundamentals enter a report as **context**, cited with a source and a date. A
technical report should never claim a view on valuation without a filing.

## Rules

1. **Every fundamental figure needs a filing date and a period** (e.g. "Q2 FY26, filed 2026-11-12").
2. **Restated figures differ from originals** — use point-in-time data for any historical test.
3. **Consolidated vs standalone** are different numbers; say which.
4. **No fabricated ratios.** If you do not have the inputs, do not compute.
5. **A good company is not a good trade** at every price, and a bad company can trend up for months.
