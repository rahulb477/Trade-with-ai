# Beginner Trading Education Engine

The teaching layer. Everything here must be understandable by someone who has never opened a chart.

| File | Purpose |
|------|---------|
| [`glossary.md`](glossary.md) | ~90 terms, English + Hinglish, one-line meaning each |
| [`hinglish-explanations.md`](hinglish-explanations.md) | Templates for explaining charts in simple Hinglish |
| [`concept-lessons.md`](concept-lessons.md) | Full lessons: definition → simple → technical → example → mistakes → exercise |
| [`exercises.md`](exercises.md) | A graded exercise set with answer guidance |

## The teaching standard

Every explanation must pass this test:

> Could a person who has never seen a candlestick read this and correctly describe what is happening on the chart?

If not, simplify. In particular:

| Don't | Do |
|-------|-----|
| "Bearish momentum divergence with a failed retest of the anchored VWAP" | "Price made a new high but the strength behind it fell, and buyers could not hold the level — so the move looks tired." |
| "The R:R is unfavourable" | "The possible gain is smaller than the possible loss, so it is not worth taking." |
| "Confluence of supply zones" | "Two reasons point to the same price area." |
| Assume the reader knows what a wick is | Define it the first time |

## Language policy

- **English section first** (so the technical terms are visible), **Hinglish summary second** (so it is
  understandable).
- Hinglish = Hindi grammar and vocabulary written in Latin script, with English trading terms kept in English
  (because that is how Indian traders actually speak): "price resistance ke upar close hua", "stop loss lagao".
- Never use Hinglish to be vague. It is a translation layer, not a simplification excuse.
- Numbers, levels and conditions must appear identically in both languages.

## The five-part lesson structure

Every concept gets:

1. **Definition** — one sentence.
2. **Simple explanation** — no jargon, an everyday analogy.
3. **Technical explanation** — the mechanics, thresholds, and edge cases.
4. **Chart example** — what it looks like, and what to check.
5. **Common mistakes** and **a practical exercise**.

See [`concept-lessons.md`](concept-lessons.md).
