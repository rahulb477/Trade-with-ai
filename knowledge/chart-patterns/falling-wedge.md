# Falling Wedge

**Type:** Reversal / accumulation (bullish implication) · **Bars:** typically 15–60

## 1. Shape
**Both** boundaries fall and **converge** — lower highs and lower lows, but in a narrowing channel. Price keeps
making new lows, yet each push down achieves less, and the range compresses.

```
 ╲╲╲
    ╲╲╲
        ╲╲╲
            ╲╲╲   converging
```

## 2. Formation rules
| # | Rule |
|---|------|
| 1 | Both boundaries have a negative slope |
| 2 | They converge |
| 3 | ≥2 touches each side |
| 4 | Usually follows a decline, but can appear during an advance as a bull-flag-like pause (then it is a
flag, not a reversal wedge — check the prior trend) |
| 5 | Volume typically contracts as price falls |
| 6 | Confirmation: a **close above the upper boundary** |

## 3. Interpretation
Selling is losing force. Each new low is achieved with less downside progress and less volume. When the upper
line breaks, the shorts who kept pressing are trapped.

As with the rising wedge, the bias is a bias, not a certainty. A falling wedge inside a powerful downtrend
sometimes resolves downward as a continuation. The confirmation decides.

## 4. Volume
Contracting volume on the decline is the classic signature. Rising volume on the decline contradicts the
accumulation reading and suggests the decline is still healthy (i.e. more downside likely).

## 5. Confirmation and entry
```
Confirmation : close above the upper boundary of the wedge
Entry        : breakout close, or a retest of the broken upper line that holds
Volume       : expansion on the breakout
```

## 6. Measurement
```
height = widest part of the wedge
target = breakout point + height
```
Worked: start width 28 (600 high, 572 low), breakout 588 → target 616.

## 7. Invalidation
Close back below the upper boundary after a break; a decisive break below the lower boundary (downward
resolution); no break and continued compression (the pattern stays `DEVELOPING`).

## 8. Common false signals
| False signal | Guard |
|--------------|-------|
| Parallel falling channel called a wedge | Require convergence |
| One touch per side | Require ≥2 |
| Volume expanding on the decline | Contradicts the reading |
| Breakout into heavy resistance | Room check |
| Confusing with a descending triangle | Triangle has a **flat** bottom; wedge's bottom falls |
| Wedge inside a strong downtrend | Context; continuation is possible |

## 9. Worked example (fictional)
```
Instrument EFG · 1D · decline 300 → 262 in a narrowing channel
Upper line: 288 → 278 → 271 · Lower line: 262 → 268 → 271 (converging)
Volume: falling 2.4M → 1.0M ✔
Breakout: close 274 on 1.9× volume → CONFIRMED
Width at start = 288 − 262 = 26 → measured target 300
Structural target: prior swing high 294 (nearer)
Invalidation: close below 268 (last low)
Retest entry 272 · stop 267 · risk 5 · T1 294 = 4.4R ✔ · T2 300 = 5.6R ✔
Note: with a stop that tight the position size is large — verify the notional exposure (§core/risk-management.md).
```

## 10. Beginner summary (Hinglish)
**Falling wedge:** dono lines **neeche** ja rahi hain, par ek doosre ke paas aa rahi hain (converge).

**Matlab:** price neeche to ja raha hai, par har naya low kam force aur kam volume par ban raha hai — selling
thak rahi hai. Isliye **bullish** bias.

**Signal:** upar wali line ke **upar close**.

**Target:** wedge ki width, breakout se upar project.

**Galti:** descending triangle samajh lena. Triangle mein neeche wali line **flat** hoti hai; wedge mein
neeche jaati hai — aur dono ka signal ulta hota hai.
