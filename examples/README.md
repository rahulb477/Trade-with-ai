# Examples

Seven worked examples showing each mode and each output shape.

> **Every example uses a fictional instrument and invented prices.** They are labelled `FICTIONAL` at the top of
> each file. They exist to demonstrate *method and format*, never market data. Do not treat any number here as a
> real price, and do not reuse the conclusions.

| Example | Demonstrates | Mode |
|---------|-------------|------|
| [`chart-analysis.md`](chart-analysis.md) | The full 16-stage pipeline + 10-section report | RESEARCH |
| [`candlestick-analysis.md`](candlestick-analysis.md) | Pattern rule auditing and status codes | LEARNING |
| [`multi-timeframe.md`](multi-timeframe.md) | Timeframe alignment table and conflict handling | RESEARCH |
| [`no-trade-analysis.md`](no-trade-analysis.md) | An honest `WAIT` — the most important output | RESEARCH |
| [`paper-trade-analysis.md`](paper-trade-analysis.md) | A complete hypothetical plan with cost arithmetic | PAPER-TRADING |
| [`market-research.md`](market-research.md) | Context research with and without web access | RESEARCH |
| [`backtest-and-ml.md`](backtest-and-ml.md) | Backtest disclosure, then why ML detection is not shipped | RESEARCH |

## How to read an example

1. Note the **quality score** first — it determines what the rest of the report is allowed to say.
2. Watch for the `ASSUMED` markers: they appear wherever a value was not printed on the chart.
3. Every example ends with **missing data** and **what would change the verdict**. That is the part beginners skip
   and professionals read first.
